# ALARM CLOCK
This is a custom alarm clock based off of an ESP32C3, and a generic buzzer.

# Parts
It uses 6 Cherry MX keyswitches with custom 3d-printed keycaps, a buzzer, a XIAO SEEED ESP32C3, and a 2.25in TFT screen

# CAD
The CAD for this project is done on onshape. It has 3 shells, a bottom slip, and 3 different types of buttons.
